# gcs
Atividades GCS

Estrutura de exemplo para exercício de Gerência de Configuração.

Como executar:

- Instale Python 3.11 (ou superior compatível).
- Carregue o arquivo de configuração `config.env` ou exporte variáveis de ambiente.
- Execute o aplicativo de exemplo:

	powershell: `python src/main.py`

O arquivo `config.env` fornece valores básicos (APP_NAME, APP_ENV, APP_VERSION).
